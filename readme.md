
# Task Manager — Multi-Container Application

A task-management application built to learn Docker, Docker Compose,
REST API development, PostgreSQL, Redis, React, testing, and debugging.

## Architecture

- Frontend: React with Vite
- Backend: Node.js and Express
- Database: PostgreSQL
- Cache: Redis
- Container orchestration: Docker Compose

## Planned Features

- Create, list, view, update, and delete tasks
- Persist task data in PostgreSQL
- Cache suitable read operations with Redis
- Validate requests and handle errors consistently
- Test application logic and API integration
- Run the stack locally using Docker Compose

## Repository Structure

- `frontend/`: React application
- `backend/`: Express API, database access, cache integration, and tests
- `compose.yaml`: Multi-container service configuration
- `.env.example`: Example configuration names and placeholder values
